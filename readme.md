# 🛡️ Aurora Launcher's GoGuardian Bypass Method:

The GoGuardian Bypass is a simple script that allows you to bypass the GoGuardian filter on your school or organization's network using iFrames. 
This tool was based off of the Aroria GoGuardian Bypasser, a FOSS tool. Link to the original repo:
https://github.com/AroriaNetwork/GoGuardian-Bypass/


## 🚀 Features
1. GoGuardian Bypass: Access blocked websites on your school or organization's network with the GoGuardian bypass script.
2. Easy to Use: Simply type in the URL of the blocked website and click the "Launch" button to create an iFrame that displays the blocked content.
3. Tested URLs: The site contains game site URLs already proven to work with the tool.


## ⚙️ How it Works
When you type in a blocked URL into the site, a JavaScript program generates an iFrame that displays the blocked content without being detected by GoGuardian. This allows you to access websites that would otherwise be blocked by the filter.

## 👩🏼‍💻 How to Use
1. Download:
 - Clone this repository to your local machine.
 - If you want to change the code or deploy the site yourself, open the index.html file in a text or code editor (like VSCodium).
2. Use:
 - On software like VSCode and VSCodium, right-click on the index.html tab and select "Copy Path" and paste it in your browser, or deploy it yourself, or use a pre-existing site.
 - Type in the URL of the blocked website you want to access into the box.
 - Click the "Launch" button.
 - The blocked content should now be displayed in the iFrame.
 - This can be useful for loading game sites and alternative search engines.
